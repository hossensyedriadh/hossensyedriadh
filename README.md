## 👨‍💻 About Me

I'm a **Backend Software Engineer** passionate about building reliable, scalable, and maintainable software systems.

My primary expertise lies in the **Java and Spring ecosystem**, with a strong interest in enterprise application development, software architecture, database engineering, and distributed systems.

I enjoy understanding the bigger picture behind software — from designing domain models and database schemas to implementing application security, managing distributed communication, and deploying applications to production environments.

I'm particularly interested in financial technology, banking infrastructure, and systems where reliability, consistency, security, and performance are critical.

**A few things about my engineering mindset:**

- 🏗️ Architecture matters. I value clean boundaries, modularity, and maintainable designs.
- 🔍 Understand the problem before choosing the technology.
- 🔐 Security and data integrity should be architectural considerations, not afterthoughts.
- ⚡ Performance optimization should be driven by understanding and measurement.
- 🧩 Prefer simplicity over unnecessary complexity.
- 📚 Continuous learning is an essential part of being an engineer.
